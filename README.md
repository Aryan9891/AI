## 🌟 Features of this Repository
- **Interactive Web Portal**: Deployed via GitHub Pages at **[https://aryan9891.github.io/AI/](https://aryan9891.github.io/AI/)**, allowing instant one-click copying of:
  - **All assignments combined** (All Python code / Complete Master Guide).
  - **Each assignment separately** (Python script, function explanations, or execution output).
- **Dual Formats**:
  - Individual **Jupyter Notebooks (`.ipynb`)** for interactive execution cell-by-cell in JupyterLab.
  - Standalone **Python Scripts (`.py`)** with full documentation.
- **Detailed Documentation**: Every single folder contains a `README.md` breaking down every function, parameter, return value, and output.
- **Master Compilations**:
  - `ALL_EXPERIMENTS_MASTER_GUIDE.md`: Unified markdown report containing all 9 experiments.
  - `ALL_EXPERIMENTS_MASTER_NOTEBOOK.ipynb`: Unified master notebook containing all 9 experiments in one file.

## 🚀 How to Run

### Option 1: Live Interactive Web Portal
Visit **[https://aryan9891.github.io/AI/](https://aryan9891.github.io/AI/)** to browse code, copy individual or all assignments with 1 click, or view markdown explanations.

### Option 2: In JupyterLab
1. Start JupyterLab from the workspace root:
   ```bash
   jupyter lab
   ```
2. Open any individual notebook (e.g., `Exp_1_Vacuum_Cleaner_Agent/exp1_vacuum_agent.ipynb`) or `ALL_EXPERIMENTS_MASTER_NOTEBOOK.ipynb`.
3. Click **Run $\rightarrow$ Run All Cells**.

### Option 3: Command Line (Python)
Run any experiment directly:
```bash
python Exp_1_Vacuum_Cleaner_Agent/exp1_vacuum_agent.py
python Exp_2_Utility_Vacuum_Cleaner/exp2_utility_vacuum.py
python Exp_3_Graph_Representation_BFS_DFS_Dijkstra/exp3_graph_searches.py
```
